## Description

**True Randomness** is a Level 9 divination spell invented by Rudy. With the Astral Dice, the caster creates a fresh number every time a prophecy is signed.

The multiplier engraved on the dice is public, but its hidden push remains secret.

Three prophecies were signed, and the Astral Vault was sealed using the same private magic.
