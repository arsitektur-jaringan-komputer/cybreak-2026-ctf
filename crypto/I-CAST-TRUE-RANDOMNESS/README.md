# I CAST TRUE RANDOMNESS!

## Author

TSakuyaiba

## Difficulty

Hard

## Description

**True Randomness** is a legendary divination spell invented by Rudy.
The Astral Dice are rolled in pairs, their echoes twisted together. The
scribe records only the upper half of each omen.

Every eighth omen, Rudy offers one extra roll to the gods. That roll never
appears in the log.

> "I CAST TRUE RANDOMNESS!" -> NAT 20!

After 2,400 omens, eight more rolls become the key to the Astral Vault.
Rudy leaves you the ritual and the scribe's log.

"You cannot predict what you cannot see... right?"
