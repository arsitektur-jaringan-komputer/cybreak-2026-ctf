# I CAST ARCANE LOCK... TWICE!

## Author

TSakuyaiba

## Difficulty

Easy


## Description

**Double Arcane Lock** is a cooperative abjuration spell used to protect a
secret scroll. Rudy locks the scroll first, then Seria locks the result.
Each wizard chooses a secret numerical incantation from a small spellbook.
The starting runes are different for every casting, but the two incantations
stay the same.

Rudy raises his staff: "I CAST ARCANE LOCK!" — NAT 15!

Then Seria follows: "I CAST ARCANE LOCK!" — NAT 20!

Surely it is twice as secure... right?
